## How to run

```sh
python3 main.py        # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```

`main.py` uses only the Python standard library, writes the same bytes on
every run, and reads the output back to verify it before exiting.
